# Project: Simple To-Do List with HTML, CSS and JavaScript

This will be a single-screen project. At the top, there will be a text field to add a new task and a submit button.

When a task is submitted, it will be added to a list displayed right below the text field.

Tasks will be stored in an array within the JavaScript itself, without using any external tool or system.

Each task has:
- text
- a boolean confirming whether it is done or not

Regarding the possible actions on each task:
- Mark/unmark it as completed, which strikes through the text (via a CSS class).
- Delete a task, so it disappears completely from the list.
- Add a new task through the text field at the top of the screen, which will always be added with the completion boolean set to false.

The project will be built using plain HTML, CSS and JavaScript.

In the JavaScript, always work with EventListeners instead of adding events directly in the HTML.

At the beginning of the JavaScript, select into variables all the elements that will be manipulated.

Graphical interface:
- The project's background will be a light gray.
- Both the input field and the list will sit in separate cards, with a white background, rounded corners, and a slight gap between the cards.
- The predominant color for the buttons (such as the add and delete buttons) will be dark green.
