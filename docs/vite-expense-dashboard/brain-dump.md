Project: Expense Dashboard

The project will use Vite with Vanilla TypeScript.

Visual presentation of the project:

    A card to add a new expense.

    List of all added expenses, positioned below the card for adding a new expense.

In the left sidebar, we will have the following information:

    Total sum of all expenses

    Total for each category

Each expense:

    id: string

    title: string

    amount: number

    category: Category

The categories are fixed:
"food", "transportation", "leisure", "health", "others"

The project will use simple HTML, CSS, and TypeScript (vanilla).
All event listeners must be added in TypeScript, not inline in the HTML.

All types must be located in the src/types.ts file.

There will be no data persistence.

Use simple and easily maintainable code.
